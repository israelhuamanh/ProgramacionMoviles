# Laboratorio 1-6: Clínica Salud+

Este directorio contiene el desarrollo de la aplicación "Clínica Salud+" (Opción A). 
El proyecto está dividido en dos versiones:
- `sinIA/`: Versión correspondiente a la Fase 1, desarrollada sin uso de asistentes de Inteligencia Artificial.
- `conIA/`: Versión correspondiente a la Fase 2 y 3, que incorpora mejoras funcionales con IA y refactorización orientada a objetos.

## Requerimientos Funcionales

1. **Filtro por especialidades**: El sistema permite al usuario visualizar categorías médicas y filtrar la lista de profesionales disponibles seleccionando una especialidad específica.
2. **Catálogo de profesionales médicos**: La aplicación muestra una lista detallada de médicos que incluye su nombre completo, especialidad, calificación promedio y cantidad de reseñas.
3. **Consulta de perfil detallado**: El usuario puede acceder a una vista ampliada de cada médico que presenta su información completa, una descripción profesional y una opción directa para agendar.
4. **Agendamiento y asignación de citas**: El sistema provee controles de selección única para que el usuario pueda definir de manera exclusiva una fecha y hora para su nueva cita médica.
5. **Gestión de citas programadas**: La aplicación cuenta con una sección dedicada a listar todas las citas reservadas por el usuario, indicando claramente el estado actual de cada una (Confirmada o Cancelada) y permitiendo la cancelación en las citas confirmadas.
